ANCHOR

An attention and working-memory layer for Figma's infinite canvas. Built for designers with ADHD. Better for everyone.

Anchor gives a Figma file a memory for what you were doing, so your own working memory can rest. It has three parts, and the demo below walks through each one inside a mock Figma file.

What each feature does, exactly

Each part of Anchor takes something a designer with ADHD would otherwise hold in their head and hands it to the file. All three are reversible, run on your own machine, and stay off until you turn them on.

1 · Tunnel
What it does
You select the frames you mean to work on and type what you're here to do. Every other frame on the page drops to 12% opacity and locks. Teammates' cursors, comment pins and notifications are muted for the session. Your intent line and a quiet elapsed-time count stay in view.
What it never does
Delete anything, hide anything from teammates, or change the file for anyone else. Exit Tunnel restores every frame exactly as it was.
Accessibility basis
W3C cognitive accessibility guidance: Help users focus and the Limit interruptions pattern. WCAG 2.2.4 Interruptions.
2 · Park it
What it does
While you're in a Tunnel, Anchor watches which frames you edit. After 15 minutes of editing outside the scope (you choose the threshold), it asks once, with three choices. Park it, Make it the intent, or Keep going. Park it moves the tangent to a Parking lot page with a dated note and a link back, then returns you to the scope.
What it never does
Ask twice in one session, delete the tangent, or use guilt copy. If you dismiss it twice, the threshold doubles.
Why
Hyperfocus tangents are often where the best ideas come from. The goal is to make them cost minutes instead of an afternoon.
3 · Where was I?
What it does
Each session, Anchor logs the frames you touch, your last selection, your intent and the note you leave, on your own machine. When you reopen the file it shows one card with when you were here, for how long, what you set out to do, what you touched, what you parked, and your note. Take me there selects and zooms to where you stopped.
What it never does
Send data anywhere, or show it to teammates or admins. The log is per user, per file, and can be cleared.
Accessibility basis
W3C cognitive accessibility guidance: Ensure processes do not rely on memory. WCAG 3.3.7 Redundant Entry.

Why Anchor counts as accessibility

Anchor - Why
i
  • It's common. The CDC estimates 6% of US adults had a current ADHD diagnosis in 2023. Over half were diagnosed as adults, so many working designers are learning this on the job, with no accommodations.
  • It's a disability in law. Under the ADA as amended, concentrating and thinking are major life activities. A substantial limit on them is a disability, judged without regard to medication. The UK Equality Act 2010 applies a similar test.
  • The standards already name these needs. The W3C's cognitive accessibility guidance has objectives called Help users focus and Ensure processes do not rely on memory, and a pattern called Limit interruptions. WCAG 2.2 has success criteria for interruptions, timing and redundant entry.
  • Figma's accessibility work so far is sensory and motor. Screen reader support, keyboard navigation and enhanced contrast are real and good. Nothing yet addresses attention or memory. Anchor is the first concrete proposal for that layer.
  • Curb cut. Built for the permanent case (ADHD), Anchor is just as useful in the temporary one (burnout, a newborn, a concussion) and the situational one (a 40-person file with twelve live cursors on a Friday afternoon).
Sources and the full concept, including metrics, risks and a validation plan, are in the concept document linked below.

Try the plugin prototype

Anchor - Install

All three features exist as a working Figma plugin prototype. The Plugin API can't mute comments or read version history, so the prototype fakes neither; the re-entry summary is rule-based and swapping in an AI-written one is a single function.

  1. Open the Figma desktop app and any file with a few top-level frames.
  2. Plugins → Development → Import plugin from manifest, and pick manifest.json from the plugin folder.
  3. Run Anchor. Select a frame, type an intent, press Enter Tunnel. Set the drift nudge to 1 minute to see Park it. Close and reopen for Where was I?
